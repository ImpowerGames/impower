## Decisions from execution-path inspection

| Area | Finding | Required implementation and evidence |
| --- | --- | --- |
| Discovery | Skills have one harness-specific source and no project agent entry point for another runner. | Move all nine skills with Git to `.agents/skills`; install ignored junctions on Windows and symlinks on POSIX. Keep one shared instructions source read from both entry points. Verify discovery in fresh headless sessions. |
| Link installation | Git cannot materialize junctions with the checkout settings. | A bare Node postinstall creates links, validates the target and refuses populated directories, foreign links and unsafe parents. Exercise idempotence and target preservation in scratch repositories on both platforms. |
| CLI dispatch | Both browser drivers compare the lexical command path with the resolved module path. A linked invocation can silently execute no command. | Compare real paths for CLI dispatch and exercise nonempty status output through each link. |
| Runtime state | Drivers derive their root at the same directory depth, but cleanup and cross-worktree download guards spell one layout. Existing worktrees can still own live servers in that layout. | Use canonical state paths and retain explicit migration lookup for existing worktrees, without probing the same linked driver twice. Test fallback and canonical/link equivalence. |
| Capabilities | Skill invocation, file writing, session naming, private artifacts and review spawning name harness tools. | State capabilities in shared skills; keep concrete mappings in one runner note. Missing required capabilities block that step explicitly; optional naming may be skipped. |
| Hook coverage | Typed issue creation, generated-language edits and the shared stash are guarded by local hooks; safe artifact writing is a prose rule. | Make all rules explicit in shared instructions regardless of hook availability. Retain harness hooks and settings in their own directory. |
| Review identity | Shared review text selects pinned models and fallback families and assumes runtime introspection. | Require caller-supplied writer identity, reviewer route and invocation method; distinguish configured route from independently reported identity; abort missing or matching identities and disclose unavailable introspection. |
| Review execution | The skill assumes parallel subagents, parent termination and that absent comments mean stopped reviewers. | Support fresh serial sessions with identical diff and prompt; wait for process exit and verify paginated comments before adjudicating or writing. Durable launch records prevent duplicate relaunch and support automatic implement/review handoffs. |
| Reviewer definitions | The two model definitions duplicate stance, probe restrictions and reporting instructions. | Generate minimal pin/abort definitions from one runner configuration; put the review contract in the shared prompt. Check generation and allowed exceptions. |
| Shell and filesystem | Generic bash resolves to unavailable WSL on this machine. `resolve-issue` recommends recursive deletion despite junction risk. | Resolve Git for Windows bash explicitly; replace the cleanup suggestion with the guarded cleaner and scratch-only experiments. Keep one vitest process, one fork and a 1 GB heap. |
| POSIX acceptance (#505) | Current tests skip process matching and ignored-link assertions. The matcher unconditionally folds case and backslashes, including on POSIX. | Assert native path semantics on each platform, preserve Windows coverage, assert actual POSIX symlink status and retain external-target sentinels. Demonstrate red/green and complete the small-ticket resolve workflow on the combined PR. |
| CI and checks | Discovery and sparse checkout cover only the harness tree. Several checks use literal paths and mutation strings. | Update paths and discovery together; run shared, hook and installer checks on Windows and Linux. Derive totals and fail empty/missing/unsupported checks. Add mutation controls for forbidden references and execution assumptions. |
| Feedback | The ninth skill archives durable problem identities and runner session references. | Move its scripts and references intact; preserve archive parsing and reporting. Report concrete friction through the standing inbox with a stable session identity. |
