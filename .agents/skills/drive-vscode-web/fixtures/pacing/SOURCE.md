# Source of the pacing fixture's assets

Every asset in `project/assets` is original and was generated by `generate.mjs` in this folder. The project contains no third-party art or sound.

- Art is procedural: shapes, curves and colour bands computed from fixed seeds, written as SVG text or as PNG files encoded in Node with `node:zlib`.
- Sound is synthesised in Node from sine tones, decaying plucks, bell partials and filtered seeded noise, then encoded in the RFC 6716 codec with the WebCodecs `AudioEncoder` of the Chromium that the repository's Playwright pins, and written into an Ogg file (RFC 7845) by `generate.mjs`. The script decodes each file again in that Chromium and checks its duration and that it is not silent.

Regenerate every asset with `node .agents/skills/drive-vscode-web/fixtures/pacing/generate.mjs` from the repository root. The same Node and Chromium versions give the same bytes.

| File | What it is |
| --- | --- |
| `project/assets/nova.svg` | The portrait of the character `nova`, 1600 by 1200, 277 paths: hair strands, a patterned coat, and the `eyes.open`/`eyes.closed` and `mouth.closed`/`mouth.teeth`/`mouth.open` layers that the `blink` and `talk` morphs drive. |
| `project/assets/dusk.svg` | A vector backdrop, 1600 by 900: a gradient sky with stars, clouds, a sun and five ridges of hills. |
| `project/assets/emblem.svg` | A vector picture, 512 by 512: a brass rosette shown on the authored `sigil` element. It has no morph. |
| `project/assets/hall/90 sky.png` | Bottom layer of the layered bitmap backdrop `hall`, 2400 by 900: banded night sky. |
| `project/assets/hall/50 towers.png` | Middle layer of `hall`: towers with lit windows on a transparent ground. |
| `project/assets/hall/10 lanterns.png` | Top layer of `hall`: hanging lanterns with glows. |
| `project/assets/vista/90 sea.png` | Bottom layer of the layered bitmap backdrop `vista`, 2400 by 900: banded sky and sea. |
| `project/assets/vista/50 isles.png` | Middle layer of `vista`: island silhouettes. |
| `project/assets/vista/10 sails.png` | Top layer of `vista`: sail boats. |
| `project/assets/theme.ogg` | Music, 28 seconds, stereo Ogg (RFC 7845) at 40 kbit/s: an arpeggio, a pad and a bass over a four-chord loop. |
| `project/assets/chime.ogg` | Sound effect, 1.6 seconds, mono Ogg (RFC 7845) at 32 kbit/s: two bell strikes. |
| `project/assets/whoosh.ogg` | Sound effect, 1.2 seconds, mono Ogg (RFC 7845) at 32 kbit/s: a swept noise rush. |

`project/main.sd` and `lines.json` are written by hand.
