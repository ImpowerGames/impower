# The audio loading fixture

A second pacing fixture whose sounds decode while measured narration lines play, in VS Code's Game Preview, where Chromium has no decoder for the RFC 6716 codec and the player's fallback decoder runs (I-2815). The main pacing fixture in `../pacing/` decodes its sounds while the preview is stopped, before any measured line, so it cannot show this work.

```bash
node .agents/skills/drive-vscode-web/driver.mjs pacing --code <VS Code executable> --project .agents/skills/drive-vscode-web/fixtures/pacing-audio/project --line 6 --beats 8 --runs 2 --keep-trace --out <evidence-directory>
```

`project/main.sd` sets `predict_distance = 1`, so each sound loads one or two beats ahead of the line that plays it, and puts the sounds two scenes away from the start line. The first sound the script plays (`bell.ogg`, on line 19) is loaded by the stopped preview before RUN; the second (`voyage.ogg`, on line 22) is fetched and decoded while line 20 plays. Read line 20's kept trace for page-thread tasks after the click: the fallback decoder's work for a three-minute stereo file lands there. Lines 7 to 24 are narration, with no pictures.

## Assets

Every asset in `project/assets` is original and was generated by `generate.mjs` in this folder, which shares its encoding and Ogg writing with the main fixture's generator through `../ogg-sounds.mjs`: synthesised in Node from sine tones and decaying partials, encoded with the WebCodecs `AudioEncoder` of the Chromium that the repository's Playwright pins, written into an Ogg file (RFC 7845), and decoded again in that Chromium to check its duration and that it is not silent. The project contains no third-party sound.

Regenerate both files with `node .agents/skills/drive-vscode-web/fixtures/pacing-audio/generate.mjs` from the repository root.

| File | What it is |
| --- | --- |
| `project/assets/voyage.ogg` | Music, 180 seconds, stereo Ogg (RFC 7845) at 24 kbit/s: plucked arpeggios, a pad and a bass over a four-chord loop. |
| `project/assets/bell.ogg` | Sound effect, 1.8 seconds, mono Ogg (RFC 7845) at 32 kbit/s: one bell strike. |
