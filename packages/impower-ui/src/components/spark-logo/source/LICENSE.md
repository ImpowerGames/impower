# Spark Engine logo and wordmark

Sparky and the Spark Engine wordmark are the maintainer's own work, copied unchanged from the `logo/` folder of the private Spark Engine design repository, and may be published. The design repository's restriction on redistributing art covers only its demo project's third-party art, not these files.

- `spark_engine_logo_cutout.svg`: Sparky with his eyes cut out. `SparkLogo` draws its mark from this file, and `impower-dev/scripts/generate-icons.mjs` renders the app icons and favicon from it in Charcoal's colours.
- `spark_engine_wordmark.svg`: the two-line "spark engine" wordmark. `SparkLogo` draws its wordmark from this file in the theme's ink.
- `spark_engine_wordmark_on_dark.svg`: the same wordmark coloured for dark grounds, kept as the design repository ships it.
