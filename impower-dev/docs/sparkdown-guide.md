`scene the_rumour`
Starts a scene inside this script.

`IMANI:`
Starts dialogue for a character.

`[[imani:happy]]`
Shows a character or expression.

`[[show backdrop sky_night]]`
Changes the backdrop.

`choose`
Starts a choice menu.

`+ [Your option]`
Shows the option every time.

`* [Your option]`
Shows the option only the first time you encounter this choice.

`then … end`
Brings the paths back together.
